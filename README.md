# Module 03 — Amazon S3 & Cloud Storage

## Project: Static Portfolio Website (S3 Hosting Practice)
A sample portfolio website created for practice with Amazon S3 object storage and static website hosting.

## Learning objectives
- Understand S3 buckets, objects, and storage classes
- Create and configure a bucket
- Upload and manage website files
- Explore basic bucket permissions and access controls
- Practice the static website hosting workflow

## Files
- `index.html` — responsive sample portfolio site
- `LINKEDIN_POST.md` — draft post

## Deployment outline (not yet performed)
1. Create an S3 bucket with a globally unique name.
2. Upload `index.html`.
3. Enable static website hosting and set `index.html` as the index document.
4. Configure appropriate access for the chosen hosting method.
5. Test the website endpoint.

This package contains practice files; it does not claim an S3 bucket has been created or that the site is live.
